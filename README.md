# Pasta Explorer

**Subtitle:** A Simple Guide to the History, Types and Recipes of Pasta

This is our first-year college Web Development mini-project built by a team of 4 students using HTML5, CSS3, and basic Vanilla JavaScript.

**Live Website (Vercel):** https://pasta-explorer.vercel.app

---

## Project Structure

```text
PastaExplorer/
│
├── index.html       (Home Page)
├── history.html     (History of Pasta & Simple Timeline)
├── types.html       (Popular Pasta Varieties with Search & Category Filter)
├── recipes.html     (8 Simple Pasta Recipes with Ingredients & Method)
│
├── css/
│   └── style.css    (Basic styling, grid layout, and responsive media query)
│
├── js/
│   └── script.js    (Pasta search, category filter, and recipe show/hide)
│
├── images/          (Local pasta and recipe images)
│
└── README.md        (Project documentation)
```

---

## How to Run the Project

1. Download or copy the `PastaExplorer` folder to your computer.
2. Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, etc.).
3. Use the navigation bar at the top to switch between **Home**, **History**, **Pasta Types**, and **Recipes**.

No server, database, or internet installation is required.

---

## Features

1. **Home Page (`index.html`):** Introduction to the project, a "Explore Pasta" button linking to the types page, and 3 featured pasta cards (Spaghetti, Penne, Ravioli).
2. **History Page (`history.html`):** Short readable sections covering what pasta is, early history, pasta in Italy, how it became popular worldwide, modern production, and a simple vertical timeline.
3. **Pasta Types Page (`types.html`):** Displays 16 popular pasta types across 5 categories (Long Pasta, Short Pasta, Stuffed Pasta, Tube Pasta, and Soup Pasta). Includes a JavaScript search box and category filter dropdown.
4. **Recipes Page (`recipes.html`):** Contains 8 classic pasta recipes with images, ingredient lists, numbered preparation steps, and a button to show or hide the recipe details.
